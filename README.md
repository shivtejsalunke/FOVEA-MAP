# FOVEA-MAP
Foveated Multi-Layer Elevation Mapping for Real-Time Dynamic Environment Perception in Autonomous UGVs.


Adaptive variable-resolution 2.5D LiDAR perception for autonomous UGVs, preserving elevation, obstacle, clearance, terrain, semantic, dynamic and temporal information while allocating finer spatial resolution to near-field regions.

Python | PyTorch | Open3D | NumPy | ROS 2 | CUDA
